# Phase 5 — Remote Access 🔐

## Overview

This phase documents the secure remote administration layer for the homelab.

By the end of Phase 5, the lab includes:

* Tailscale-based private remote connectivity
* secure SSH access to both Raspberry Pi nodes
* off-site remote validation without router port forwarding
* a cleaner administrative path with reduced exposure
