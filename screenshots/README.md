# Screenshots 📸

This folder contains redacted screenshots used as validation evidence for the Home Network Infrastructure Lab.

Screenshots are included to show that each phase was configured, tested, and verified.

---

## Screenshot Purpose

Screenshots support:

- Implementation proof
- Validation evidence
- Troubleshooting notes
- Phase completion criteria
- Portfolio presentation

---

## Redaction Standard

Before screenshots are committed, sensitive values are redacted or excluded.

Redacted items include:

- Public IP addresses
- Private details not needed for documentation
- Provider account details
- Secret values
- API keys
- Webhook URLs
- Passwords
- Authentication tokens
